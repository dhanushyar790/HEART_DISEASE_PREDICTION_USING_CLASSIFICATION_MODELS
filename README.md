**🫀 Heart Disease Prediction using Machine Learning**
**📌 Project Overview**

This project focuses on predicting heart disease using multiple Machine Learning Classification Algorithms. The dataset is preprocessed, outliers are handled using Winsorization, and features are standardized before training the models.

The main objective is to compare different machine learning models and identify the algorithm with the best prediction accuracy for heart disease detection.

**🎯 Objectives**
-- Analyze medical dataset features
-- Perform data preprocessing and feature scaling
-- Detect and handle outliers
-- Train multiple machine learning models
-- Compare model performance using accuracy metrics
-- Visualize correlations and prediction results

---

**✨ Features**
-- Exploratory Data Analysis (EDA)
-- Outlier Detection using Boxplots
-- Outlier Treatment using Winsorization
-- Feature Scaling using StandardScaler
-- Multiple ML model implementation
-- Confusion Matrix visualization
- Correlation Heatmap analysis
-- Accuracy comparison graph
-- Performance evaluation of models

  ---
  
**🤖 Machine Learning Models Used**
-- Decision Tree Classifier
-- Random Forest Classifier
-- Support Vector Machine (SVM)
-- K-Nearest Neighbors (KNN)
-- Naive Bayes Classifier

**📊 Model Accuracy Comparison**
-- Model	Accuracy
-- Decision Tree	98.53%
-- SVM	98.53%
-- Random Forest	97.07%
-- KNN	82.93%
-- Naive Bayes	81.95%

---

**📈 Project Insights**
-- Decision Tree and SVM achieved the highest accuracy.
-- Random Forest also performed exceptionally well with high prediction accuracy.
-- KNN and Naive Bayes showed comparatively lower performance.
-- Feature scaling improved model consistency.
-- Correlation heatmaps helped identify important relationships between features.
